🎮 Memory Matrix

Über das Projekt

Memory Matrix ist ein kleines Gedächtnisspiel, bei dem Konzentration, Aufmerksamkeit und Merkfähigkeit gefragt sind. Das Ziel ist es, sich die Reihenfolge der aufleuchtenden Felder zu merken und diese anschließend korrekt nachzuklicken.

Das Projekt wurde mit HTML, CSS und JavaScript entwickelt und ist ein praktisches Beispiel für die Umsetzung eines interaktiven Browser-Spiels.

🕹️ Wie funktioniert das Spiel?

1. Klicke auf „Spiel starten“, um eine neue Runde zu beginnen.
2. Beobachte die leuchtenden Felder auf dem Spielfeld.
3. Merke dir die Reihenfolge und klicke die Felder in derselben Reihenfolge an.
4. Mit jeder erfolgreichen Runde wird die Sequenz länger und das Spiel schwieriger.
5. Wenn du ein falsches Feld anklickst, ist das Spiel vorbei.
6. Starte erneut und versuche, deinen bisherigen Rekord zu übertreffen!

✨ Funktionen

- Interaktives Spielfeld mit neun Feldern
- Zufällig generierte Sequenzen
- Schrittweise steigender Schwierigkeitsgrad
- Anzeige der aktuellen Runde
- Speicherung des persönlichen Rekords im Browser
- Modernes Design mit leuchtenden Feldern
- Responsive Gestaltung für kleinere Bildschirme

🛠️ Verwendete Technologien

- HTML5 – Struktur der Webseite
- CSS3 – Design, Layout und Animationseffekte
- JavaScript – Spiellogik, Benutzerinteraktionen und Spielstand
